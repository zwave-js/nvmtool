# Online Z-Wave NVM editor

Interactive web-based utility to edit Z-Wave NVM files.

## Usage

Visit https://zwave-js.github.io/nvmtool

## Contributing

AI assistance is welcome when contributors personally review, understand, and
can explain every change. Autonomous-agent contributions and unreviewed
AI-generated communication are prohibited. See the [AI policy](AI_POLICY.md)
for the full requirements.
